# DeskFinger

DeskFinger 是一个用于管理桌面项目、快速启动项、一键启动流程和 Markdown 文档的 Tauri 桌面小工具。

## 功能

- 首次使用时选择运行目录；项目配置、启动项和项目文档都会保存在该目录下。
- 维护项目卡片：支持新建、编辑、删除项目，项目包含名称、描述、图标、颜色、快速启动项和一键启动项。
- 管理快速启动项：支持文件夹、应用程序、文档文件、网页和终端命令。
- 支持把文件、文件夹或应用程序拖入项目，自动推断启动项类型并加入快速启动。
- 快速启动支持点击打开、手动添加、编辑、移除、加入一键启动、自由排序、按名称排序、按类型分组，以及卡片/列表两种视图。
- 一键启动支持按顺序执行多个已启用动作，可单独启用/禁用、上移/下移、立即执行、编辑或移除动作。
- 终端命令启动项支持 CMD 和 PowerShell，多行命令会按顺序执行，并可选择执行完成后保留终端窗口。
- 应用程序启动项支持启动参数；网页启动项会在缺少协议时自动补全 `https://`。
- 每个项目带独立 Markdown 文档目录，默认创建 `看板.md`；支持新建、读取、编辑、自动保存、手动保存、重命名、删除。
- Markdown 文档支持编辑、分屏和预览模式，预览使用 GitHub Flavored Markdown。
- 软件只保存外部资源的路径链接，不拷贝被启动的文件夹、程序或文档资源本身。

这是一个通过 vibe coding 完成的小型个人产出，不具有严谨性、通用性和使用安全性，仅供我个人使用和参考。
