# DeskBot

DeskBot 是一个像素风桌面机器人，使用 Tauri 2、React、TypeScript 和 Vite 实现。

## 功能

- 透明桌面舞台：显示一个像素风宠物窗口，支持置顶、跳过任务栏、拖动位置，并把宠物位置写入本地配置。
- 宠物交互：单击宠物会显示问候气泡并展开悬浮球；长按拖动后会触发落地动画。
- 点击穿透：舞台透明区域会尽量穿透到桌面或下层窗口，宠物和悬浮球区域保留可点击热区。
- 悬浮球：当前包含对话球和额度球，对话球打开聊天面板，额度球刷新并打开额度面板。
- 面板窗口：包含对话和额度两个 tab，自定义标题栏，支持显示/隐藏、放大/还原和右下角拖拽调整大小。
- Kimi Code 对话：通过本机 `kimi acp` 子进程桥接 ACP 协议，支持会话初始化/恢复、流式回复、工具调用展示、权限请求处理、停止当前回复和消息排队。
- Kimi 工作区：对话会话使用 `workspace/` 作为 cwd，`workspace/AGENTS.md` 作为机器人人格文件。
- 额度查询：读取 `KIMI_API_KEY` 环境变量或本地 `deskbot.local.json` 中的 `apiKey`，查询 Kimi Code API 的周额度和 5 小时窗口额度。
- 额度联动宠物状态：周额度和 5 小时窗口使用情况会影响宠物的高光、变暗、瞌睡、汗滴或过热表现。
- 后台轮询：额度信息会定时刷新，并在每次对话完成后尝试刷新。
- 系统托盘：提供显示/隐藏宠物、打开对话和退出应用。
- 单实例运行：重复启动时会聚焦已存在的面板或显示宠物。
- 本地配置：`deskbot.local.json` 可保存 Kimi API Key、API Base URL、Kimi CLI 路径、workspace 目录、会话 ID、宠物位置和宠物显示状态。

这是一个通过 vibe coding 完成的小型个人产出，不具有严谨性、通用性和使用安全性，仅供我个人使用和参考。
